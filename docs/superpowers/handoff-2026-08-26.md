## 3. 環境まわりの既知の落とし穴(再発見済み・そのまま適用可)

- **`EnterWorktree` が古い `origin/master` から分岐するバグ**: 新しいworktreeに入ったら `git log --oneline -2` を worktree側とmaster側で比較し、ズレていて未コミット変更が無ければ `git reset --hard master`。
- **`preview_start({name:...})` はworktree内でcwdを取り違える**: worktree内では `Bash` で `node scripts/dev-server.js` を `run_in_background:true` で直接起動し、その後 `preview_start({url:"http://localhost:8430"})` で繋ぐ。named configは使わない。
- **`git worktree remove` がWindowsでファイルロックに失敗する**: マージ前にPowerShellで `dev-server.js` を実行中の `node.exe` を `Stop-Process -Force` してから `git worktree remove`。
